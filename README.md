Implementing a ChatGPT App with LangChain from Scratch

This repository demonstrates how to build a conversational AI application from scratch using modern LangChain (v1.2+) and OpenAI models. It walks through the progression from a basic stateless prompt-response chain to a stateful chatbot with in-memory session tracking and persistent JSON-based chat history.

📋 Features

Modern LCEL Architecture: Uses LangChain Expression Language (prompt | llm | StrOutputParser()) instead of legacy LLMChain patterns.

Custom System Personas: Demonstrates how to enforce specific response behaviors (e.g., translating or restricting output to German).

In-Memory Chat History: Implements RunnableWithMessageHistory and InMemoryChatMessageHistory to maintain conversational context during an active session.

Persistent Session Storage: Uses FileChatMessageHistory to save and reload conversations locally in JSON format (chat_history.json).

📂 Repository Structure

├── chat_history.json    # Sample saved conversation session generated by the notebook
├── requirements.txt     # Python dependencies and exact package versions
└── notebook.ipynb       # Step-by-step Jupyter Notebook implementation (rename to match your .ipynb file)


🚀 Getting Started

Prerequisites

Python 3.10+ (tested on Python 3.13)

An OpenAI API Key

Installation

Clone the repository:

git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name


Create and activate a virtual environment:

python -m venv .venv
# On Windows:
.venv\Scripts\activate
# On macOS/Linux:
source .venv/bin/activate


Install the required packages:

pip install -r requirements.txt


Set up environment variables:
Create a .env file in the root directory and add your OpenAI API key:

OPENAI_API_KEY=your_openai_api_key_here


💻 Usage

Launch Jupyter Notebook or JupyterLab:

jupyter notebook


Open the project notebook and run the cells sequentially:

Cell 1–2 (Basic Chatbot): Loads environment variables and runs an interactive terminal loop using gpt-3.5-turbo configured to respond only in German. Type quit, q, exit, or bye to stop.

Cell 3 (In-Memory History): Upgrades the chain with MessagesPlaceholder and RunnableWithMessageHistory so the model remembers previous turns within the session.

Cell 4–5 (Persistent History): Switches the backend to FileChatMessageHistory, automatically saving messages to chat_history.json and inspecting the stored HumanMessage and AIMessage objects.
